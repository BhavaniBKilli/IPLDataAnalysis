🏏 IPL Analysis Dashboard (2008–2025)

 📌 Project Overview
This project is an interactive Power BI dashboard that analyzes Indian Premier League (IPL) data from 2008 to 2025. The dashboard provides insights into team performance, player statistics, tournament winners, and season-wise analysis using interactive visualizations.

 🚀 Features
- Season-wise IPL analysis (2008–2025)
- Champion and Runner-up details
- Total Matches, Teams, Venues, Fours, Sixes, Centuries, and Half-Centuries
- Orange Cap and Purple Cap winners
- Top Fours and Top Six hitters
- Interactive Points Table
- Season filter (Slicer) for dynamic analysis
- Clean and user-friendly dashboard design

 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel

 📊 Dashboard Insights
- IPL season champions and runner-up teams
- Top run scorer (Orange Cap)
- Top wicket taker (Purple Cap)
- Team standings and points table
- Season-wise batting and bowling statistics
- Overall tournament summary

 🎯 Skills Demonstrated

- Interactive Dashboard Design
- Data Visualization
- Business Intelligence (BI)
